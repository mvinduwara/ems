# Project Name
Retail HR Employee Management System (EMS)

# Features <br>
Role-Based Dashboards: Separate interfaces for Admin and Employee users. 
Employee Management: Tools to maintain employee records, roles, departments, and positions.  
Time and Attendance: Capabilities to log attendance, supported by built-in QR code badge generation and scanning utilities. 
Leave Management: Employees can submit leave requests, which administrators can review and approve. 
Payroll Processing: Automated payroll generation tools for admins and personal payslip viewing for employees.  
System Auditing: Dedicated audit logs to track user actions and system changes. 
Theming: A responsive UI that supports both light and dark themes.

# Tech Stack & Project StructureLanguage <br>
Java  Build Tool: Maven (pom.xml) 
UI Framework: JavaFX (utilizing FXML files for layout and CSS for styling)  
Database Mapping: JPA/Hibernate (configured via META-INF/persistence.xml) 
Fonts: Integrated Poppins font family (Bold, Medium, Regular, SemiBold)
